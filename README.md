## 🏗️ **System Architecture**

### **Frontend (React + Vite)**
- **Modern job portal interface** with responsive design
- **Smart resume builder** with AI suggestions and multiple themes
- **Job browsing and application system**
- **User authentication and profile management**
- **Real-time notifications and status updates**
- **Career bot for job guidance**

### **Backend (Node.js + Express)**
- **RESTful API** for job management and applications
- **User authentication** with JWT tokens
- **File upload processing** for resumes
- **Database management** with MongoDB
- **Integration with ML service** for resume analysis
- **Email notifications** and alerts

### **ML Service (Python + Flask)**
- **Resume analysis and scoring** using advanced NLP
- **Skill extraction** from PDF/text with spaCy
- **Experience detection** and validation using regex patterns
- **Job matching algorithms** (TF-IDF, cosine similarity)
- **Fraud detection** for job postings
- **Real-time processing** with instant results
